# Changelog

All notable changes to the CompassKB knowledge base.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versions are date-based (`YYYY.MM.N`) because a knowledge base has no API
surface to version semantically.

Sections used here: `Added`, `Changed`, **`Corrected`**, `Deprecated`,
`Removed`, `Security`. `Corrected` means the KB previously stated something
false — it exists so a reader who acted on the old answer knows to re-check.
See `.claude/skills/release-notes/SKILL.md`.
